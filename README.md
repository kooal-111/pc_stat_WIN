# PC Stat 1.2.0 (Windows 11)

Локальное приложение на Python: учёт **активного** времени за компьютером и по приложениям.

- **Активное время** — пока есть ввод с клавиатуры или мыши и прошло меньше порога AFK (по умолчанию 120 с после последнего ввода).
- **Время по приложению** — по активному окну (foreground), **одна строка на приложение (exe)**. При отсутствии ввода дольше порога AFK время не копится (ни для ПК, ни для приложения).
- **Время с загрузки Windows** — из текущей сессии (`psutil` / время загрузки ОС).

Данные хранятся в SQLite: `%LOCALAPPDATA%\pc_stat_win\data.sqlite`. Активные интервалы буферизуются и сохраняются одним batch примерно раз в 30 секунд, при смене приложения, AFK, sleep и выходе, поэтому фоновая работа почти не создаёт дисковой нагрузки.

**Имена и иконки в таблице:** отображаемое имя берётся из ресурсов версии Windows (`FileDescription` / `ProductName` в exe); если их нет — из имени файла. Иконка — системная для этого exe (как в Проводнике), с кэшированием.

**Иконка самого PC Stat:** окно, панель задач и трей используют общий значок из `pc_stat_win/assets/app.png` (генерируется при сборке; свой PNG — `app.png` или устаревшее имя `app_icon.png`). Для иконки файла `.exe` в Проводнике PyInstaller вшивает `app.ico` (создаётся при `build_windows.ps1`).

**Сводка и топ-5:** на вкладке «Статистика» — длительность периода, оценка времени работы ПК в периоде (по журналу загрузок), **доля активного времени от этой оценки**, полосы топ-5.

**Периоды (календарные, локальный часовой пояс):**

- **День** — с 00:00 сегодня до текущего момента.
- **Неделя** — с понедельника текущей недели 00:00.
- **Месяц** — с 1-го числа текущего месяца 00:00.
- **Год** — с 1 января текущего календарного года 00:00.
- **Всё время** — от первой записи в базе до текущего момента.

**Интерфейс:** Glass/Mica-оформление использует системный Mica на поддерживаемой Windows 11 и безопасный непрозрачный fallback. Доступны режимы «Как в Windows», тёмный и светлый; выбранный режим сохраняется в базе.

**Автозапуск:** в настройках включите «Запускать вместе с Windows» — в реестр добавляется запись в `HKCU\...\Run` с флагом **`--background`**, поэтому при входе в Windows **окно не открывается**, трекер и значок в трее работают как обычно (окно — через трей или «Открыть»). Для **установленного** `PCStat.exe` в путь попадает этот файл; из исходников — `pythonw -m pc_stat_win --background`. Обычный запуск без автозагрузки по-прежнему показывает окно (если не задано иначе в БД: ключ `show_main_window_on_launch` в таблице `meta`). На новом профиле автозапуск выключен, пользователь включает его явно.

**Доля активного времени** в сводке считается от **оценённого времени работы ПК** в периоде (сессии между записями в журнале загрузок). Пока ПК выключен, трекер не работает — интервалы не пишутся. Оценка по `boot_log` **не различает сон и работу** без дополнительных событий — это сознательное упрощение.

**Категории приложений:** расширенный набор (работа, отвлечения, общение, игры, медиа, разработка, система, браузер/веб, документы/офис, дизайн/креатив, удалённый доступ, файлы/архивы, AI/ассистенты, прочее). Правила пользователя по-прежнему важнее эвристик. Старые три значения в базе при обновлении мигрируют: продуктивное → работа, непродуктивное → отвлечения, нейтральное → прочее. История интервалов не переписывается, но отчёты могут перераспределиться по новым категориям.

**Отчёты:** раздел «Отчёты» показывает сравнение с прошлым периодом, покрытие приложениями, горизонтальные полосы категорий, топ приложений, топ «прочего» для донастройки правил и график активного времени. QtCharts загружается только при открытии отчёта.

**Экспорт CSV:** кнопка «Экспорт CSV…» сохраняет таблицу приложений за текущий выбранный период (с колонкой категории), строку итога по активному времени ПК и блок сумм по категориям. Файл в кодировке UTF-8 с BOM (удобно открывать в Excel), разделитель поля — `;`.

## Скачать готовое приложение (.exe)

**Обычному пользователю** нужен portable **`PCStat.exe`** (один файл, без Python) из **[последнего GitHub Release](https://github.com/kooal-111/pc_stat_WIN/releases/latest)**. Там же публикуется `SHA256SUMS.txt` для проверки файла. Запуск — двойной щелчок по `PCStat.exe`. Краткая памятка также в [`download/README.txt`](download/README.txt).

Как взять папку с GitHub:

- **Releases** — скачайте готовый `PCStat.exe` и `SHA256SUMS.txt` из последнего релиза.
- **Download ZIP** — содержит исходный код и не содержит готовый `download/PCStat.exe`.

**Всё остальное в репозитории** (`pc_stat_win/`, `scripts/`, `.spec` и т.д.) — **открытый исходный код** для разработчиков и сборки; для ежедневного использования приложения можно не разбираться.

Публикация репозитория и анонимность коммитов: [docs/GITHUB.md](docs/GITHUB.md).

## Локальная сборка установщика (альтернатива)

Официальный release-артефакт — portable `PCStat.exe`. Inno Setup остаётся дополнительным локальным способом собрать `PCStat-Setup.exe` (один мастер «Далее», без Python).

1. Установите [Inno Setup 6](https://jrsoftware.org/isinfo.php) (нужно только **сборщику** дистрибутива).
2. В корне репозитория выполните:

```powershell
.\scripts\build_installer.ps1
```

3. Готовый файл: **`installer\output\PCStat-Setup.exe`**.
4. Пользователь запускает установщик, по желанию отмечает ярлык на рабочем столе и «Запустить после установки». Программа ставится в `%LOCALAPPDATA%\Programs\PC Stat\PCStat.exe` (без прав администратора).

База данных по-прежнему создаётся приложением при первом запуске в `%LOCALAPPDATA%\pc_stat_win\data.sqlite` — установщик её не трогает.

### Проверка базы после первого запуска

Убедиться, что схема поднялась (в PowerShell, после того как приложение уже запускали один раз):

```powershell
sqlite3 "$env:LOCALAPPDATA\pc_stat_win\data.sqlite" "SELECT key, value FROM meta WHERE key = 'schema_version';"
```

Ожидается строка `schema_version` с числом версии схемы.

## Разработка из исходников

Откройте папку с проектом в терминале (после `git clone` перейдите в неё: `cd pc_stat_WIN`).

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt или python -m pip install -r requirements.txt
```

Если при импорте `win32` возникают ошибки, для установки через pip иногда нужно выполнить постустановку pywin32 (см. [pywin32 wiki](https://github.com/mhammond/pywin32/wiki)).

### Запуск из исходников

**Проще всего:** дважды щёлкните **`PC Stat.bat`** в корне проекта (используется виртуальное окружение `.venv`, если оно есть, иначе `python` / `py -3` из системы).

Или из терминала:

```powershell
python -m pc_stat_win
```

Иконка в области уведомлений: двойной щелчок — открыть окно. Закрытие окна **сворачивает** в трей; выход — из меню трея «Выход».

## Сборка только .exe (без установщика)

Из корня проекта:

```powershell
.\scripts\build_windows.ps1
```

Получится папка **`dist\PCStat\`** — запуск: `PCStat.exe` внутри неё. **Отдавайте всю папку** (или ZIP целиком): рядом лежат DLL и Qt.

**Один файл:**

```powershell
.\scripts\build_windows.ps1 -OneFile
```

Результат: **`dist\PCStat.exe`** — одно приложение. Можно переслать как есть или обернуть установщиком (`build_installer.ps1` выше).

**Облегчённая сборка без QtCharts:**

```powershell
.\scripts\build_windows.ps1 -OneFile -NoQtCharts
```

В этом режиме текстовые отчёты и таблицы работают, но графики QtCharts не включаются в сборку.

**Git:** не коммитьте **`build/`**, **`dist/`**, **`output/`**, **`PC Stat/`**, **`installer/output/`** и **`download/PCStat.exe`** — это локальные или публикуемые отдельно артефакты. Они в `.gitignore`. Локально очистка: `.\scripts\clean_build.ps1`.

## Версия и выпуск

Единственный источник версии приложения — `APP_VERSION` в `pc_stat_win/version.py`. Во время Windows-сборки `scripts/generate_version_metadata.py` проверяет формат `MAJOR.MINOR.PATCH` и создаёт ресурс PyInstaller в `build/PCStat_version_info.txt`; этот сгенерированный файл не коммитится. `build_installer.ps1` передаёт ту же версию в Inno Setup.

Portable release собирается и публикуется так:

```powershell
.\scripts\build_windows.ps1 -OneFile
.\scripts\publish_release.ps1
```

`publish_release.ps1` сам формирует тег `v<APP_VERSION>` и заголовок релиза, создаёт `dist\SHA256SUMS.txt` и прикладывает к GitHub Release ровно `dist\PCStat.exe` и checksum-файл. Для команды нужны установленный и авторизованный GitHub CLI (`gh`).

## Настройки

- **Тема** — системная, тёмная или светлая; Mica автоматически отключается на неподдерживаемой системе.
- **Автозапуск с Windows** — запись в реестре (см. выше); для раздачи пользователям используйте установленный `PCStat.exe`.
- **Порог AFK** — секунды без ввода, после которых вы считаетесь отошедшими от ПК (сбрасывается и активность ПК, и учёт приложения в фокусе).
- **Исключения** — имена `exe` через запятую (например `someapp.exe`), такие процессы не попадут в статистику по приложениям, даже если в фокусе.

## Ограничения

- Нет отдельного учёта «приложение открыто в фоне» — только активное окно.
- Список вкладок браузера целиком без расширения недоступен — учитывается только активное окно.
