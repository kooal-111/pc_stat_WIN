# PC Stat (Windows 11)

Локальное приложение на Python: учёт **активного** времени за компьютером и по приложениям.

- **Активное время** — пока есть ввод с клавиатуры или мыши и прошло меньше порога AFK (по умолчанию 120 с после последнего ввода).
- **Время по приложению** — только пока окно этого приложения в **фокусе (foreground)** и вы не в состоянии AFK.
- **Время с загрузки Windows** — показывается из текущей сессии (`psutil` / время загрузки ОС).

Данные хранятся в SQLite: `%LOCALAPPDATA%\pc_stat_win\data.sqlite`.

**Имена и иконки в таблице:** отображаемое имя берётся из ресурсов версии Windows (`FileDescription` / `ProductName` в exe); если их нет — из имени файла. Иконка — системная для этого exe (как в Проводнике), с кэшированием.

**Иконка самого PC Stat:** окно, панель задач и трей используют общий значок. По умолчанию он рисуется в коде; можно подложить свой файл `pc_stat_win/assets/app_icon.png` (перезапуск приложения).

**Сводка и топ-5:** на вкладке «Статистика» показываются длительность выбранного периода, число приложений, доля активного времени от длины периода и полосы для пяти лидеров (доля от **активного времени ПК** за период).

**Периоды (календарные, локальный часовой пояс):**

- **День** — с 00:00 сегодня до текущего момента.
- **Неделя** — с понедельника текущей недели 00:00.
- **Месяц** — с 1-го числа текущего месяца 00:00.
- **Год** — с 1 января текущего календарного года 00:00.
- **Всё время** — от первой записи в базе до текущего момента.

**Тема интерфейса:** в настройках можно выбрать тёмную или светлую тему; выбор сохраняется в базе.

**Категории приложений:** на вкладке «Категории» задаются правила по имени exe или фрагменту пути (продуктивное / непродуктивное / нейтральное). Для приложений без правила используется встроенный набор эвристик; иначе категория «нейтральная». В таблице на «Статистика» показывается колонка категории.

**Отчёты:** вкладка «Отчёты» — текстовая сводка за выбранный период, круговая диаграмма по категориям и график активного времени по дням (для периода «день» — по часам).

**Экспорт CSV:** кнопка «Экспорт CSV…» сохраняет таблицу приложений за текущий выбранный период (с колонкой категории), строку итога по активному времени ПК и блок сумм по категориям. Файл в кодировке UTF-8 с BOM (удобно открывать в Excel), разделитель поля — `;`.

## Установка

```powershell
cd C:\Code\python\pc_stat_WIN
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Если при импорте `win32` возникают ошибки, для установки через pip иногда нужно выполнить постустановку pywin32 (см. [pywin32 wiki](https://github.com/mhammond/pywin32)).

## Запуск

```powershell
python -m pc_stat_win
```

Иконка в области уведомлений: двойной щелчок — открыть окно. Закрытие окна **сворачивает** в трей; выход — из меню трея «Выход».

## Как отдать программу другим (без Python)

Соберите **папку с готовым `.exe`** через [PyInstaller](https://pyinstaller.org/):

```powershell
cd C:\Code\python\pc_stat_WIN
.\scripts\build_windows.ps1
```

После сборки запуск: `dist\PCStat\PCStat.exe`. **Раздавайте всю папку `dist\PCStat`** (внутри лежат DLL и Qt) — можно заархивировать её в **ZIP** и выложить на облако или в [релизы GitHub](https://docs.github.com/en/repositories/releasing-projects-on-github/managing-releases-in-a-repository) (прикрепить ZIP как asset).

Вариант для разработчиков: выложить репозиторий и в README указать установку из `requirements.txt` и команду `python -m pc_stat_win`.

**Git:** папки **`build/`** и **`dist/`** не включайте в репозиторий — PyInstaller записывает туда абсолютные пути с вашего компьютера (в т.ч. имя пользователя Windows). Они перечислены в `.gitignore`. Перед пушем при необходимости удалите их локально: `.\scripts\clean_build.ps1`.

## Настройки

- **Тема** — тёмная или светлая.
- **Порог AFK** — секунды без ввода, после которых вы считаетесь отошедшими от ПК.
- **Исключения** — имена `exe` через запятую (например `someapp.exe`), такие процессы не попадут в статистику по приложениям, даже если в фокусе.

## Ограничения

- Нет отдельного учёта «приложение открыто в фоне» — только фокус + ввод.
