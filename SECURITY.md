# Безопасность PC Stat

## Поддерживаемая версия

Исправления безопасности выпускаются для последней версии из GitHub Releases.

## Локальные данные

PC Stat хранит статистику только локально: основная база находится в
`%LOCALAPPDATA%\pc_stat_win\data.sqlite`, а CSV-отчёты создаются только по явной команде пользователя.
При обращении по безопасности не прикладывайте настоящую базу, WAL/SHM-файлы или CSV с личными путями.
Для воспроизведения используйте временную пустую базу через `PCSTAT_DB_PATH`.

## Сообщить об уязвимости

Не публикуйте сведения об уязвимости в обычном issue. Используйте приватное сообщение через
[GitHub Security Advisory](https://github.com/kooal-111/pc_stat_WIN/security/advisories/new) и укажите:

- версию PC Stat и версию Windows;
- минимальные шаги воспроизведения;
- возможное влияние на локальные данные или выполнение кода;
- логи без личных путей, заголовков окон и содержимого пользовательской базы.

Не прикладывайте `%LOCALAPPDATA%\pc_stat_win\data.sqlite`: база может содержать историю приложений
и локальные пути. Для воспроизведения используйте новую временную базу через `PCSTAT_DB_PATH`.

## Проверка релиза

Сверьте `SHA256SUMS.txt`, затем проверьте provenance:

```powershell
gh attestation verify PCStat.exe --repo kooal-111/pc_stat_WIN
```

Portable EXE пока не имеет Authenticode-подписи издателя. Это ограничение не скрывается и не
компенсируется одной контрольной суммой; официальный release публикует только артефакт из CI с
GitHub/Sigstore attestation.
