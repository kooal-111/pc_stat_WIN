PC Stat — папка для публикации готового onefile-приложения.

Если здесь есть PCStat.exe, запуск: дважды щёлкните PCStat.exe.
Если файла нет, скачайте его из GitHub Releases или соберите проект:
  .\scripts\build_windows.ps1 -OneFile
  .\scripts\sync_download_exe.ps1

Остальной репозиторий — исходный код; для обычной работы он не нужен.
