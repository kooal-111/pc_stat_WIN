# Конфиденциальность PC Stat

PC Stat работает локально. В исходном коде приложения нет сетевой отправки,
телеметрии, рекламы, облачной синхронизации или автоматической загрузки данных.

## Какие данные хранятся

- интервалы активного времени;
- имя и локальный путь активного приложения;
- пользовательские категории, правила и настройки;
- технический журнал ошибок с ротацией;
- заголовки окон только при явно включённой настройке. По умолчанию их сбор
  отключён, потому что заголовок может содержать имя документа или чата.

База находится в `%LOCALAPPDATA%\pc_stat_win\data.sqlite`, журналы — в соседней
папке `logs`. Каталог наследует ACL профиля Windows. Администратор компьютера и
процессы, работающие от имени пользователя, всё равно могут получить доступ к
этим файлам: база не зашифрована отдельным паролем.

CSV создаётся только по команде пользователя. Текстовые поля защищены от
интерпретации как формулы при открытии в табличном редакторе.

## Удаление данных

В настройках можно выбрать срок хранения 30, 90, 180 или 365 дней либо оставить историю без ограничения.
Кнопка «Удалить статистику» удаляет интервалы активности и журнал загрузок, сохраняя настройки и
правила категорий. Удаление использует SQLite `secure_delete`, обрезку WAL и `VACUUM`, чтобы ранее
сохранённые строки не оставались в свободных страницах базы. Отключение сбора заголовков окон
запускает такую же физическую очистку заголовков.

Для удаления также настроек и логов завершите PC Stat через меню значка в области уведомлений и
удалите папку `%LOCALAPPDATA%\pc_stat_win`.

## Проверка выпуска

GitHub Release содержит `SHA256SUMS.txt`. Артефакт собирается GitHub Actions и получает
криптографическую GitHub/Sigstore provenance attestation, которую можно проверить командой
`gh attestation verify PCStat.exe --repo kooal-111/pc_stat_WIN`. Portable EXE пока не подписан
коммерческим Authenticode-сертификатом, поэтому Windows SmartScreen может показать предупреждение.
Контрольная сумма и attestation подтверждают целостность и происхождение сборки, но не заменяют
цифровую подпись издателя Windows.
